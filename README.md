# 🎓 Student Management System

A simple **Student Management System** developed using **Java JSP, Servlets, JDBC, HTML, CSS, and MySQL**. This project is designed to manage student records efficiently through basic CRUD (Create, Read, Update, Delete) operations.

## 📌 Features

* ➕ Register New Student
* 📋 View Student Details
* 🔍 Search Student Records
* ✏️ Update Student Information
* ❌ Delete Student Records
* 🗄️ Store Data in MySQL Database
* 💻 Simple and User-Friendly Interface

## 🛠️ Technologies Used

## 🗃️ Database

The project uses a **MySQL** database to store student information such as:

* Name
* Password
* Date of Birth
* Gender
* Course
* Semester 

## 🚀 How to Run

1. Clone the repository.
2. Import the project into Eclipse or any Java IDE.
3. Create the required MySQL database.
4. Configure the JDBC connection with your database credentials.
5. Add Apache Tomcat Server.
6. Run the project on Tomcat.
7. Open the application in your web browser.
